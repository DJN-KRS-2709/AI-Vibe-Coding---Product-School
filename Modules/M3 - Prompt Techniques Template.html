The Fast Start: Foundational Prompts
Use when moving from a blank page to a functional V1
Meta Prompting Blank Page Cure
Ask the AI to act as an expert PM and rewrite your vague ideas into detailed, high-fidelity specifications. Cures "Blank Page Syndrome" by turning fuzzy thinking into structured specs before any code is generated.
Your prompt
E.g. "Act as a Senior PM. Rewrite my vague request for [Feature] into a detailed FUDI (Functionality, User Flow, Design, Interaction) specification. Then, use that spec to generate the prototype."
Zero-Shot Prompting 0→1 · Cold Start
Use for rapid ideation when you have no assets. Tests the AI's baseline understanding to generate an initial V1 based purely on your instructions — no examples, no references.
Your prompt
E.g. "Create a [Screen Type] for a [User Persona] that allows them to [Core Action]. Include [Specific Components]."
Few-Shot Prompting 1→N · Design Matching
Force consistency by providing examples. Guides the AI to match a specific coding style, format, or design pattern you already have. Best when you need new features to look and feel like existing ones.
Your prompt
E.g. "Here are 3 examples of our [Component] code: [ADD SCREENSHOT / Examples]. Generate a new [Feature] that matches this exact syntax and styling."

Architectural Tools: Structural Prompts
Use to build multi-screen systems and handle complex logic without the fragility gap
Chain-of-Thought (COT) Complex Logic
Prompt the AI to explain its reasoning step-by-step before writing code. Prevents logic errors in multi-step user flows by making the AI "think out loud" through validation rules, state transitions, and edge cases.
Your prompt
E.g. "Think step-by-step to define the state logic for [Flow]. First, outline the validation rules for each step. Then, write the code."
Prompt Chaining Full-Stack Features
Break complex builds into sequential steps (e.g., Database → API → UI) so the AI doesn't lose context or hallucinate. Each prompt builds on the verified output of the previous one.
Your prompt
E.g. "Create a JSON schema for [Data Type]." …WAIT FOR OUTPUT… "Build a Dashboard UI that strictly follows that schema."
Multimodal COT Design Cloning
Upload a screenshot or sketch and ask the AI to "reason" through the visual layout. Translates pixels into functional code by having the AI analyze spacing, hierarchy, and component structure before generating.
Your prompt
E.g. "Analyze this screenshot. Explain the layout logic step-by-step, then generate the code to replicate this component."
3
Enforcement Tools: Constraint Prompts
Use to ground the AI in your business rules, brand standards, and technical boundaries
Context Grounding (RAG) External Constraints
Ground the AI in your specific documents — brand guides, API docs, compliance rules. Ensures accuracy and compliance by giving the AI authoritative reference material instead of relying on its training data.
Your prompt
E.g. "Using the attached [Document], style this [Screen]. Ensure it follows the [Specific Rule / Hex Code] exactly."
4
Optimization Tools: Refinement Prompts
Use to surgically steer and polish your build without triggering a foundation reset
Self-Consistency UI/UX Options
Ask the AI to generate multiple variations of a layout or flow, then select the best one based on specific criteria. Gives you options instead of a single take-it-or-leave-it output.
Your prompt
E.g. "Generate 3 different layout concepts for a [Screen Name]. Evaluate each for [Metric, e.g., Mobile Usability] and write the code for the best one."
Reflection (Self-Assessment) Auto-Debug
Force the AI to critique its own output and identify flaws, accessibility issues, or bugs before you test. A built-in code review step that catches problems the AI itself introduced.
Your prompt
E.g. "Review the code you just generated. Identify any accessibility flaws or hardcoded values. Then, rewrite the code to fix those issues."
