The Details That Separate a Demo From a Product

Visual
  • Favicon — custom browser tab icon
  • Page title — not "Vite App"
  • Loading state — no blank flash
  • Mobile — no horizontal scroll
Functional
  • Auth — new user can sign up
  • Error handling — slow network
  • Empty states — new user view
  • Navigation — can get back
Professional
  • Meta tags — link preview
  • Performance — under 3 sec
  • Copy — no "Lorem ipsum"

You don't need all green. But you should know which ones are red.
