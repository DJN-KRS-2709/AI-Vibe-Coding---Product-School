Credits Strategy
Lovable gives ~100 credits/month. You can burn through them in a single session. Here's the strategy experienced builders use to get 5x the output from the same credits.
1
Plan in Gemini or ChatGPT
Structure your prompt, iterate on wording, test your logic. Zero credits burned. This is where 60% of the work happens.
2
Paste into Lovable
When the prompt is polished, paste it in. One generation. No trial-and-error burning credits on half-baked prompts.
3
Fix in Code When Possible
A typo? Wrong color? Misaligned element? Edit the generated output directly instead of re-prompting. Save credits for structural changes only.
!
When to Eject
Prompted twice and it's still broken? Stop. You're in a credit death spiral. Export the code to ChatGPT, debug there, paste the fix back. Save your credits for building, not debugging.

Speaker Notes

On Credits: "Before the lab — this will save you. Lovable gives about 100 credits a month. If you prompt, re-prompt, re-prompt without a plan, you'll burn through them in 20 minutes. The strategy: plan in a free tool first (ChatGPT, Gemini), paste the polished prompt into Lovable in one shot, and fix small things in code instead of re-prompting."

On Ejecting: "Most important tip for the lab: if you've prompted twice and it's still broken — stop. Do not keep prompting. That's rage-prompting and it burns credits with zero return. The pro move: copy the code, paste it into ChatGPT, ask it to find the bug, paste the fix back into Lovable. You just saved 5 credits."
