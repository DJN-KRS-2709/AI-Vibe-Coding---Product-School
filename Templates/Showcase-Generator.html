Showcase Generator

Paste your GitHub repo URL. The tool scans every markdown file in your repo, finds the right sections, and renders your final project showcase — ready to deploy on GitHub Pages.

What the tool looks for in your repo

It crawls every .md file and pattern-matches H2 headers (##) to find these sections:

  • Product link · any https://*.lovable.app URL anywhere in your markdown
  • Problem · any heading matching ## Problem (often inside livingprd.md)
  • Hypothesis · any heading matching ## Hypothesis
  • Validation · any heading matching ## Validation or ## Assumptions (often a separate validation brief)
  • Living PRD elements · metrics + scope sections in livingprd.md
  • Prompt chain · fenced code blocks inside any file with prompt in the path
  • Engineering handoff · content of engineeringhandoff.md or files under 04-handoff
  • Friction · any heading matching ## Friction or ## What broke
  • Key learnings · any heading matching ## Learning or ## What I learned
  • Aha moment · any heading matching ## Aha or ## Aha moment

If a section is missing, the showcase still renders — that slide becomes a clear placeholder telling you exactly what to add to your repo.

No login required. Public repos only. Uses GitHub's public API · rate-limited to 60 requests per hour per IP.
